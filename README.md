# Python Programs Repository

This repository contains basic Python scripts and utilities.

## Hello World

Run the Hello World script:

```bash
python3 hello.py
```

## Calculator

A simple calculator module with basic arithmetic functions (`add`, `subtract`, `multiply`, `divide`).

Run the calculator sample:

```bash
python3 calculator.py
```

Run unit tests:

```bash
python3 -m unittest test_calculator.py
```
